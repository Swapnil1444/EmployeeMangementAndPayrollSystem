# Employee Management and Payroll System

## 📌 Project Overview
The Employee Management and Payroll System is a console-based Java application designed to manage employee information and payroll operations. It uses JDBC to connect the Java application to a MySQL database.

## 🚀 Features
- Employee management (CRUD operations)
- Department management
- Attendance management
- Payroll processing and salary calculation
- MySQL database connectivity

Additional features such as PDF payslip generation, email notifications, reports, or data export should be listed only if they are implemented and working in the project.

## 🛠️ Technologies Used
- **Programming Language:** Core Java
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Concepts:** Object-Oriented Programming (OOP), CRUD operations, exception handling

## ⚙️ Prerequisites
- Java JDK
- MySQL Server
- An IDE such as Eclipse or IntelliJ IDEA
- MySQL JDBC Driver

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in your Java IDE.
3. Create the required database and tables in MySQL.
4. Configure the database URL, username, and password in the project configuration.
5. Add the required JDBC driver and other project dependencies.
6. Run the application's main Java class.
